# Vigil

Welcome to the public support and community space for Vigil, an app for praying the traditional Divine Office and reading Scripture and Christian texts.

- [Report a bug or text error](https://github.com/awesomecon/vigil-app/issues/new/choose)
- [Ask a question or share a feature idea](https://github.com/awesomecon/vigil-app/discussions)
- [Read the privacy policy](https://awesomecon.github.io/vigil-app/)

Search existing issues and discussions before opening a new topic. If someone has already reported your problem, add any useful details to that report.

For prayer or calendar errors, include the date, hour, language, and selected calendar or rubrics, if available. For reading errors, include the work or Bible translation and the passage.

Please remember that issues and discussions are public. Remove personal information from screenshots and logs before sharing.

Please be kind, stay on topic, and respect other people's traditions. This space is for using and improving Vigil.
